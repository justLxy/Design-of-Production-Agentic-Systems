What the agent does. It triages Bandit alerts on a Python project. For each alert it decides label 1 (a potential vulnerability) or label 0 (a false positive), cites line ranges as evidence, and, for label 1 only, edits the flagged file to fix the weakness. The targets are OWASP BenchmarkPython (about 3,700 callables, one test case per file under testcode/ plus helpers/), Radicale and SGLang.

How the agent runs code. The harness offers the model a tool run_python(code). Each call runs the code in a persistent Python 3.12 namespace inside an OpenShell sandbox, like a notebook cell: variables, imports and functions defined in one call are still there in the next one, also across alerts. The tool returns everything written to stdout and stderr (including output from subprocesses), the repr of the last expression if the code ends with one, and the traceback if the code raises. Long output is cut in the middle, so the agent should print compact results. One call may run for at most 600 seconds; after a timeout the kernel restarts and the namespace is empty. The working directory is the workspace copy of the target. Two names are predefined in the namespace: WORKSPACE (the absolute path of that copy, for example /sandbox/work/target) and ALERT (a dict for the open alert with alert_id, test_id, path relative to WORKSPACE, line, severity, confidence, issue_text and code). The model submits its label through a separate submit tool, not from Python, so the file does not need to cover submitting.

Sandbox limits the agent must know about. There is no network except the model provider, so pip install and downloads fail. The agent can read only the code directories of the target and its workspace copy, and can write only inside /sandbox and /tmp. It must never read the OWASP answer key (expectedresults-*.csv), .git or the .codeanalyzer cache, and on OWASP it should read only the file of the open test case plus helpers/. It must never run the target's code. The bandit command is installed and can be run with subprocess to rescan a file after an edit. A permission error from the operating system means the sandbox refused the access; the agent should not try to get around it.
